# No-paid-API development and evaluation paths

Checked: November 13, 2026 (UTC). English is primary; Japanese summary below.

## Current decision

Current Kaggle requirements allow self-hosted development without GCP billing, followed by a switch to an eligible Google model for the entry. This corrects the earlier conclusion that development artifacts must have been generated by the final declared Argon model. It does not establish a usable runtime: the local inference preflight stopped before inference because resource-safety prerequisites could not be verified. No paid API, GCP or model call was made. See the [research and preflight record](experiments/2026-11-13-rules-and-local-preflight.md).

## Current competition requirements

The live [Kaggle Overview](https://www.kaggle.com/competitions/physical-engineerings-last-exam/overview), Evaluation / Minimum Requirements 3–4, permits genuine development artifacts from a self-hosted open-weight model or personal subscription/API without requiring GCP/Vertex billing. Personal APIs are not necessarily free and paid APIs remain outside this project's scope.

Before committing the Stage 2 entry, `model_api` may be changed to one of the eight eligible `google-cloud/<id>` models, including Argon. Disclose the actual local model and judge configuration in the Writeup. Paid local judging is not mandatory; organizers rescore artifacts. Do not call local-model outputs measured Argon results, reuse another entry's outputs, fabricate artifacts or treat the model-switch allowance as permission for arbitrary post-run harness changes.

Both `kit check` and `kit artifacts` must pass. Development artifacts must be actual, untouched, unpacked `eval/run.py` exports, at most 512 MiB and 10,000 files, with no Git LFS or symlinks. The inspected page does not specify a special validation order after the permitted model switch. Inspect command behavior and billing independently before execution.

[Rules B.2](https://www.kaggle.com/competitions/physical-engineerings-last-exam/rules) allows one competition entry per team, not one per day. The Overview permits a Writeup of at most 2,000 words to be unsubmitted, edited and resubmitted before the deadline. Neither inspected page supplies a numerical daily retry allowance.

## Sponsorship and billing boundaries

- Sponsored Stage 2 evaluation is for the top 100 Stage 1 entries, with 56 hidden tasks run three times. It is not an on-demand free development API. Direct registration/submission at ple-bench.com is closed; use the current Kaggle Writeup route.
- The [Google announcement](https://cloud.google.com/blog/products/ai-machine-learning/introducing-physical-engineerings-last-exam-for-agents) advertises sponsored models on organizer servers. The official kit's [November 9 documentation commit](https://github.com/google-research/ple/commit/8320f0402fdca9f42476607f72bcfd5271cd50c9) removed earlier registration/submission and organizer-evaluation promises. Current Kaggle requirements are more specific. No Kaggle page modification date was displayed, so no exact publication sequence is asserted.
- [General Argon pricing](https://aistudio.google.com/docs/pricing#gemini-4-argon) excludes Argon from the Free tier. No participant-specific free Argon development allocation or numerical quota has been verified.
- The [official local Vertex proxy](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/docs/models.md#running-google-cloud-models-on-your-machine) bills the participant's GCP project. Do not use it here.
- The [current evaluator](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/eval/README.md) can invoke a separate default Claude Opus 5.5 judge. Permission to avoid paid local judging does not make the default command free.

## Useful work without provider calls

- Inspect source and run focused synthetic/mock tests, keeping their results separate from real runtime checks and benchmark scores.
- Use the official source validator in an existing environment. At kit revision `8320f0402fdca9f42476607f72bcfd5271cd50c9`, [cmd_validate](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/__main__.py#L66) calls [spec.load](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/spec.py#L161) for local YAML/schema checks, without running install/serve commands, a model, judge or Docker.
- Review artifact structure after genuine exports exist. The [artifact inspection command](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/__main__.py#L296) is distinct from evaluation and may hash files or invoke Git. Inspect its scope and Git configuration first. Do not import another entry's artifacts with `--from`.

`uv run` can provision dependencies and is not synonymous with a purely local validation call. `kit check`, including `--no-smoke`, still tests model connectivity. `eval/run.py --artifacts` can call the judge. These commands were not run in this review.

## Source-only feasibility: checks-only pilot, not executed

At pinned kit revision `8320f0402fdca9f42476607f72bcfd5271cd50c9`, selecting only tasks whose actual metadata says `grading = "checks"` avoids the kit's LLM-judge requirements and verifier judge environment ([judge gates](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/eval/run.py#L2716-L2764), [staging](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/eval/run.py#L2793-L2822)). This is a possible no-paid-judge route, not a passing run or a guarantee that all task/harness code is network-free. The real local model and programmatic verifier must run successfully; [exports require measured trials](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/export.py#L459-L490).

Preserve the export's [actual local model and harness provenance](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/export.py#L89-L132). Changing `model_api` afterward changes the harness hash, which the pinned [artifact validator reports as a warning, not an automatic refusal](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/artifacts.py#L2846-L2928). Do not rewrite the manifest to disguise the local model as Argon. This technical behavior does not expand Kaggle's model-switch permission or prove reproducibility/eligibility.

Full `kit check` remains a separate gate: a [local-model entry is marked not ready](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/check.py#L990-L1006), while a declared Google model [requires a real configured proxy](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/check.py#L772-L807). A legitimate zero-charge final Argon check remains unresolved; substituting local weights behind an Argon label would not resolve it.

The [evaluation CLI](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/eval/run.py#L3293-L3406) has no request cap, token cap or shortened agent-timeout option. [Task staging overwrites the agent timeout](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/eval/run.py#L1347-L1369) with the [six-hour kit limit](https://github.com/google-research/ple/blob/8320f0402fdca9f42476607f72bcfd5271cd50c9/kit/spec.py#L32), even with existing `--tasks-dir` data. `--trials 1` and `--attempts 1` do not bound model requests within a task. A future pilot needs separately verified request/token limits, per-request and total time limits, and bounded cleanup. One task is not necessarily fast or within a one-request budget; interruption may leave no measured export. No ready-to-run command or successful test is claimed here.

## Remaining gates

Verify an existing runtime and model/license identity, sufficient resources without interfering with concurrent work, explicit local-only routing, no cloud fallback, bounded execution and cleanup. The failed preflight is not permission to bypass a resource check, install/download a model or change machine settings. A safe synthetic smoke run would still not be a competition score or required artifact export. Data access, Docker, pinned-runtime behavior, official checks and genuine development artifacts remain unfinished.
